# Aventura de recuerdos

Una pequeña aventura hecha para navegador con HTML, CSS y JavaScript. No requiere instalar nada.

## Probarlo

Abre `index.html` en un navegador. En computadora, muévete con **WASD** o las **flechas** e interactúa con **E**. En móvil aparecen controles táctiles.

## Publicarlo con GitHub Pages

En el repositorio, ve a **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**, selecciona la rama `main` y la carpeta `/(root)`, y guarda. Cuando termine la publicación, GitHub Pages mostrará el enlace de tu sitio en esa misma sección.
